Project Overview
DG Library & Venue Hub is a digital platform designed to make it easier for students to discover, access, and manage learning resources and information about available study spaces.
The project brings important academic resources, course information, learning pathways, timetables, and venue details together in one accessible platform. It is designed with a clean and responsive interface so that students can easily navigate the information on both computers and mobile devices.

## Development & Contribution Workflow

1. Pull the latest changes from the main branch.
2. Create a branch using the assigned Jira task key.
3. Make the required development or documentation changes.
4. Test the changes locally before committing.
5. Check the website for layout, functionality and responsive issues.
6. Stage the completed changes using Git.
7. Commit the changes with a clear commit message.
8. Push the branch to GitHub.
9. Create a Pull Request for review.
10. Address feedback and verify the changes before merging.
